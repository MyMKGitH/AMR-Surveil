# Security policy

## Supported versions

Security fixes are intended for the latest tagged release. This repository is an early research/portfolio release and has not undergone a formal security assessment.

## Reporting a vulnerability

Please do not post secrets, patient data, access tokens, unpublished sequences, or exploitable details in a public issue. Use GitHub's private vulnerability reporting feature where available. If unavailable, contact the maintainer through the contact channel published on the GitHub profile.

## Data handling

- Do not commit real patient data, direct identifiers, restricted isolate metadata, API keys, passwords, private model weights or access tokens.
- The Hugging Face Space is intended for synthetic or properly licensed public data only. Do not upload confidential or identifiable clinical data to a public deployment.
- Process governed clinical data only in an institutionally authorised, access-controlled environment.
